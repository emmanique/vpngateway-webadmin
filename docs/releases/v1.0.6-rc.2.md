# v1.0.6-rc.2 — Host traffic accounting repair

Release candidate (not stable). Reports VPN per-host RX/TX from interface/direction-specific nftables rules rather than rule-list positions; excludes management HTTPS counters. Reports blocked packets/bytes distinctly from approved traffic, and resets the accumulated-traffic namespace to avoid importing historical corrupted totals. Includes counter regression tests and dashboard localization updates.

Known limitations: LAN HTTPS exception for blocked clients is currently runtime-only; persistence after firewall reconciliation/reboot is not yet implemented. Clients with a different default router can bypass the gateway's blocked policy. These conditions block final stable approval.
