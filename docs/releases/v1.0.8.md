# VPN Gateway Multi v1.0.8

- \`start.sh\` instala/activa o serviço de estado NAT-PMP no Linux host, ligado exclusivamente ao IP e à interface LAN de gestão (TCP/9443).
- Mantém a API administrativa autenticada por bearer token.
- Novo endpoint read-only \`/api/v1/port-forward/authorized-host\`: apenas responde para o próprio host Stremio com IP, MAC (vizinho de kernel), policy ID e mapeamento activos. Recusa acesso de outros hosts.
- Compatível com o observador automático e fallback 6881 do Stremio Standalone RC9.
- A revogação da política bloqueia imediatamente novas observações do host, sem alterar regras fora dos controlos existentes do Gateway.

## Limites de segurança e aceitação

O endpoint automático pressupõe uma LAN fiável e protegida contra IP/MAC spoofing. O primeiro contacto no cliente usa TOFU (certificado guardado/fixado), não uma PKI preaprovada; não usar em segmentos com clientes não confiáveis. Não expor TCP/9443 à Internet. Um mapeamento NAT-PMP verificado localmente não comprova acessibilidade externa de peers. A validação em QA inclui a recusa por origem errada e a sincronização real da porta no host autorizado.
