# VPN Gateway Multi v1.0.6 — Stable

Scope: the VPN Gateway's own management and dataplane. The upstream router is outside this project's release validation.

## Included
- Per-host counters for VPN RX/TX by actual nftables interface/direction, and separate blocked packets/bytes.
- Management HTTPS exception for blocked hosts, constrained to their IP, MAC, LAN interface and this gateway's Docker HTTPS proxy.
- Controller startup recovery and periodic reconciliation of Docker-proxy destination IP changes.
- Continued support for DIRECT, VPN WireGuard/OpenVPN and BLOCKED, with no broad management bypass.
- Operator warning that BLOCKED applies to traffic traversing this gateway, not another router.
- The MediaHub observer installer remains disabled until credentials/CA verification; the installer cannot automatically activate port synchronization.

## Validation (2026-11-09)
- API: 138 tests passed, 28 subtests.
- Integration: 368 tests passed, 52 subtests.
- Docker webadmin image builds successfully, with i18n and TypeScript build checks.
- On gateway 192.168.1.235, policy-agent and UI are operational; management policy routing was removed and recovered upon controller restart; a host-policy blocked test incremented dropped counters; the VPN-assigned Stremio host continued to route via WireGuard.

The release does not configure any external router, switch, or client default gateway. In deployments where managed hosts can reach a different gateway, enforcement must be provided by the network owner.
